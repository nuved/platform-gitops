Everything Nuved does

Every line is something you can use today, and the tag says where. What is being built is listed apart, at the bottom.

Money

  • Top up by card through Stripe (test mode during the preview)console
  • Charged by the hour for what each project reserves, at rates derived daily from our AWS billconsole, API
  • At zero, services pause and nothing is deleted; a top-up brings them back as they wereautomatic

Projects

  • Each project is its own isolated namespace with CPU and memory caps you setconsole, CLI, API
  • No internet egress by default; one NetworkPolicy of yours opens it, and cloud metadata stays closedkubectl
  • Give a service a public HTTPS address in a second, and take it away againconsole, nuved expose
  • Plain kubectl: download a kubeconfig for one projectconsole, nuved kubeconfig

Coding agents

  • An agent token can't top up, change caps, or reach another project; it is refused with a sentencekube.nuved.io
  • A skill that teaches Claude Code, Codex or Cursor what it may do herenuved skill install

People and sign-in

  • Teammates share one organization's balance, projects and tokensconsole
  • The CLI signs in with a code you approve in the browsernuved login

Tools

  • The CLI: curl -fsSL https://get.nuved.io/install.sh | shget.nuved.io
  • The whole API, documented, with every call the console makesapi.nuved.io/docs
