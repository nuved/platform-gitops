How it works

The homepage says what you get. This page says what actually runs, because the part worth judging is what the platform refuses to do.

Four steps

A different piece of the platform owns each one.

  1. 1Subscribe on a plan

    Stripe Checkout takes the subscription. The signed webhook writes it to Postgres, which is the source of truth, then creates a Tenant in the cluster carrying that plan's quota. Cancelling reverses it.

  2. 2Get isolated workspaces

    The tenancy-operator turns each workspace into a namespace with a ResourceQuota, a LimitRange, a default-deny NetworkPolicy and a RoleBinding. Your plan decides how many you can have; asking for one more is refused.

  3. 3Push your manifests

    Commit a directory under apps/ and open a pull request. CI runs kubeconform and the cluster's own Kyverno policies against it, so a privileged pod fails the PR with the message admission would have given.

  4. 4Watch it go Healthy

    Argo CD syncs your directory into your namespace and reverts anything that drifts away from git. The console lists your workspaces and the live status of what runs in each one.

What runs where

Two paths reach the same namespace: a subscription creates it, git fills it. Traffic gets in through one shared Gateway and nothing else.

What the platform enforces

Every line here is a rule the cluster applies on its own, not advice in a runbook. The tag says which component refuses you when you break it.

  • One namespace per workspace, labelled with its tenant and plantenancy-operator
  • A ResourceQuota per workspace, and a LimitRange so a container that declares no requests still gets 100m CPU and 128Mitenancy-operator
  • A default-deny NetworkPolicy: pods talk to their own namespace and to DNS, nothing elsetenancy-operator
  • A RoleBinding to the built-in edit role, scoped to the one namespacetenancy-operator
  • The operator will not adopt a namespace it did not create, so deleting a workspace can never take someone else's with ittenancy-operator
  • No privileged containers, no host network, host PID or host IPCKyverno admission
  • Non-root only, no privilege escalation, all capabilities dropped, seccomp on, no hostPath, no hostPortKyverno admission
  • No PodDisruptionBudget that blocks every eviction and would stall a node drainKyverno admission
  • An Argo AppProject per workspace, locked to that namespace, this repo, and five resource kindsArgo CD
  • kubeconform plus those same Kyverno policies on every pull request, so the answer arrives before the mergeCI gate
  • A Stripe subscription is what creates a tenant; cancelling it deletes the namespaces and everything in themplans-backend

Try the sandbox

Open the console, pick a plan, and pay with Stripe's test card:

4242 4242 4242 4242, any future expiry, any CVC

The webhook creates a tenant, the operator provisions the namespace, and the console shows the workspace with its quota. Deploy something into it, then cancel the subscription from the billing portal and watch the namespace go away.

Anything you create here is public. Other visitors can see it, and it is wiped whenever the cluster is rebuilt. Do not put anything private in it.
